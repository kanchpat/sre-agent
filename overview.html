Chapter III · Progressive Disclosure Architecture (Question #08)

    
When Specialized Agents Become Repetitive: Agent Skills & Progressive Disclosure

    

      Pasting 20 different incident SOPs and runbooks directly into the system prompt burns ~20,000 tokens upfront (~5,500 tokens on every single turn) and causes instruction dilution. Progressive Disclosure (`SKILL.md`) loads only what the active incident requires.
    


    

      
      

        

          ✗ Without Agent Skills · Monolithic Prompt Stuffing
        

        
~20,000 Tokens Stuffed on Turn 0

        

          Every sub-agent carries the full markdown text of all 20 runbooks, SQL schemas, and Python diagnostic scripts whether or not the outage touches them.

            • ~5,500 tokens billed on every single LLM call

Chapter V · Executive Synthesis

    
The 4 Enterprise Architecture Blueprints

    

      Every architectural decision across the 20 questions converges on one core rule: Govern through Infrastructure, Not with Prompts.
    


    

      

        
BLUEPRINT 01 · QUESTIONS 08 & 15

        
Cost & Latency Optimization

        
Gemini 3.1 Flash Router → Progressive Skills (L1→L2→L3) → Gemini 3.1 Pro Escalation

        

          Filter 99% of routine log heartbeats with gemini-3.1-flash and keep 20 skills at ~1,000 tokens via L1 metadata, cutting token spend by 62%.
        

      


      

        
BLUEPRINT 02 · QUESTIONS 16, 17, 18 & 19

        
Zero-Trust Security & Data Perimeter

        
Agent Registry → Agent Gateway → OBO Identity → Model Armor + SCC

        

          Agents never hold god-mode keys. OBO binds actions to the human caller's IAM token, while Model Armor strips prompt injections hidden inside BigQuery logs.
        

      


      

        
BLUEPRINT 03 · QUESTIONS 05, 06, 07 & 09

        
Enterprise Continuity & Interoperability

        
Managed MCP + Knowledge Catalog → A2A Protocol → Sessions + Memory Bank

        

          MCP standardizes tool/data access, Knowledge Catalog provides business semantics, A2A bridges LangGraph sister agents, and Memory Bank recalls past incidents (`Incident-1904`).
        

      


      

        
BLUEPRINT 04 · QUESTIONS 11, 12, 13 & 14

        
Risk, Verification & Operational Reliability

        
gVisor Agent Sandbox → Independent Council → Vertex GenAI Eval + OTel

        

          Untrusted diagnostic code runs in gVisor micro-VMs (blast radius = 0), an adversarial Council verifies citations, and Vertex GenAI Eval gates every release on a 5-point rubric.
